# MollyIA · descargas y actualizaciones

Aquí se publican las versiones instalables de [MollyIA](https://mollyia.pooldeza.com/), la app para Windows y Mac que transcribe reuniones de Google Meet, Zoom y Microsoft Teams en tu propio equipo, sabe quién habló y entrega un resumen con tareas. No une ningún bot a la llamada y el audio no se sube a internet.

- **Web y prueba gratis de 7 días:** https://mollyia.pooldeza.com/
- **Microsoft Store:** https://apps.microsoft.com/detail/9PN6TXZQNHQN
- **Extensión en Chrome Web Store:** https://chromewebstore.google.com/detail/kjognebmfbmfpjjgfgkhaagfaandoncf

## Archivos de cada versión

- **Transcriptor-Setup-<versión>.exe**: Windows con GPU NVIDIA.
- **Transcriptor-Lite-Setup-<versión>.exe**: Windows sin GPU (laptops).
- **MollyIA-<versión>-mac-arm64.zip**: Mac con Apple Silicon.
- **MollyIA-extension-<versión>.zip**: extensión para Brave y Chrome.
- **SHA256SUMS.txt**: sumas que la app verifica antes de instalar.

Los instaladores de Windows conservan el nombre «Transcriptor», el nombre anterior de MollyIA, para que las instalaciones existentes se actualicen solas.

La app avisa sola cuando hay una versión nueva. Este repositorio solo contiene instaladores, no el código.
