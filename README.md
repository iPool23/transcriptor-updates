# Transcriptor · actualizaciones

Aquí se publican las versiones instalables de [Transcriptor](https://github.com/iPool23/transcriptor) (transcripción local de reuniones).

- **Transcriptor-Setup-<versión>.exe**: para PC con GPU NVIDIA.
- **Transcriptor-Lite-Setup-<versión>.exe**: sin GPU (laptops).
- **SHA256SUMS.txt**: sumas que la app verifica antes de instalar.

La app avisa sola cuando hay una versión nueva. Este repositorio solo contiene instaladores, no el código.
